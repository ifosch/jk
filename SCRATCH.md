# jk

It's a Jenkins command line tool.

## Documentation

This tool uses [bndr/gojenkins](https://github.com/bndr/gojenkins)
[(Docs)](https://pkg.go.dev/github.com/bndr/gojenkins) extensively.

You need to [create a Jenkins API
token](https://stackoverflow.com/questions/45466090/how-to-get-the-api-token-for-jenkins).
